# Configurations

> ⚠️ Il existe différents modes de fonctionnement:
> * Compteur est en mode Historique (Monophasé ou Triphasés)
> * Compteur est en mode Standard (Monophasé ou Triphasés)

## Mode Historique

Utilisez le fichier [Mode_Historique.yml](https://github.com/bastoon577-lang/Module_TIC/blob/main/HOME_ASSISTANT/Mode_Historique.yml)
puis ajoutez/supprimez les données que vous souhaitez remonter.

## Mode Standard

Utilisez le fichier [Mode_Standard.yml](https://github.com/bastoon577-lang/Module_TIC/blob/main/HOME_ASSISTANT/Mode_Standard.yml)
puis ajoutez/supprimez les données que vous souhaitez remonter.
